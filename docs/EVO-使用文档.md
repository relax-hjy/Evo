## 功能流程

### 流程 1：每日学习打卡

解决「今天学什么、学完怎么记」——每天打开系统照着做，10 分钟内完成闭环。

**操作步骤：**

1. 打开 http://127.0.0.1:8765 → 看板会给出【今日任务】3 条（系统按"复习到期 → 低分推进 → 新内容"自动排好）
2. 选第一条开始学习（看书/视频/写代码/做题均可）
3. 学完回到对应任务，点【打分】→ 在【打分弹窗】选档位（0 没碰过 / 30 见过 / 60 能用 / 80 掌握 / 95 精通）
4. 在【证据输入框】写一句"做了什么证明这个分数"（如：独立写了一个计算器）→ 保存
5. 到【日志】页补一条当天学习心得（选填）

**结果说明：** 该知识点掌握度更新、技能进度环变化；打分证据自动进日志；系统按间隔自动安排下次复习日期。

> 注意：分数必须对应真实证据——"看完了视频"最多值 30 分，能独立做出来才值 60+。这是系统的核心规则。

---

### 流程 2：到期复习

解决「学过的东西忘了」——到点自测，会就拉长间隔，不会就重学。

**操作步骤：**

1. 打开看板，右上角【🔥 连续天数】旁的红色徽标数字 = 今天到期复习条数
2. 切到【复习】页 → 列表显示到期节点（含逾期天数、当前掌握度）
3. 对第一个节点**先自己回想**（不看资料），再点【自测复习】
4. 按回想程度选：90 全想起来 / 70 想起大半 / 40 基本忘了
5. 重复直到清空列表

**结果说明：** ≥80 分 → 掌握度 +5、复习间隔拉长一档（1→2→4→7→15→30 天）；60-79 → 维持；<60 → 降档 -15 分、明天重来。结果自动入日志。

> 注意：自测的价值在于"先回想再确认"，直接翻资料再答等于没测。

---

### 流程 3：查看/维护技能树

解决「全局掌握情况如何、技能树不符合实际怎么改」。

**操作步骤：**

1. 看板点击任意【技能卡片】→ 直接进入【技能树】页并切到该技能
2. 按主题分组浏览每个知识点的【状态标签】（未开始/学习中/巩固中/已掌握/已精通）与【📅 下次复习日期】
3. 点主题行可折叠/展开；任意节点右侧点【打分】可直接修正掌握度
4. 点右上【＋ 添加节点】→ 输入标题与验证方式，新增知识点

**结果说明：** 技能进度 = 所有叶子节点掌握度平均值，树顶百分比与看板进度环实时一致。

---

### 流程 4：里程碑与成就记录

解决「阶段目标怎么跟踪」。

**操作步骤：**

1. 看板【🏁 里程碑】区勾选已达成的目标（如"交付一个 Spring Boot Web 服务"）
2. 勾选后自动写入一条项目日志（🏁 前缀），可在【日志】页回看
3. 日志页也可直接手写记录，支持关联技能

**结果说明：** 里程碑打勾即完成，进度可追溯，连续打卡天数从日志日期自动统计。

## 常见问题

**Q：双击 start.bat 提示找不到 python？**
A：本机必须用 `py` 启动器（PATH 里的 python 是微软商店占位符）。手动跑 `py -m uvicorn server:app --port 8765`。

**Q：端口 8765 被占用（提示 address already in use）？**
A：说明服务已经在跑或上次没退干净。任务管理器结束 python 进程，或换端口启动（前端地址相应改端口）。

**Q：8765 和 8766 有什么区别？**
A：8765 是现行 Python 版（日常使用），8766 是 Go 重写版（开发验证中）。双版本共用同一 data.db，数据一致。

**Q：data.db 会进 git 吗？备份怎么办？**
A：不会（.gitignore 已排除）。备份直接复制 data.db 文件即可；换机器把文件带上，放回项目根目录就能继续用。

**Q：为什么我打了 60 分，进度只涨了一点点？**
A：技能进度是**叶子节点**平均值——只给一个点打分，31 个知识点的技能只涨约 2%，这是设计行为。
