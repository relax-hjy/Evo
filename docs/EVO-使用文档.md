## 快速开始

### 安装 / 启动

```bat
:: 方式一：双击 start.bat（自动打开浏览器）
:: 方式二：直接双击 evo.exe
:: 手动（开发）：go run .   /   重新编译：go build -o evo.exe .
```

### 访问地址
- http://127.0.0.1:8765 （Go evo.exe 现行版；Python 版仅作回滚备用）

### 数据在哪
- **数据根 `D:\CloudDriver\EVO`**（由 exe 旁的 evo.json 配置）：data.db（学习进度）、课文 md、backup 快照全部在此，可整目录远程同步；代码在 GitHub 仓库，两边合体即完整系统

## 功能流程

### 流程 1：每日学习打卡

解决「今天学什么、学完怎么记」——每天打开系统照着做，10 分钟内完成闭环。

**操作步骤：**

1. 打开 http://127.0.0.1:8765 → 看板会给出【今日任务】3 条（系统按"复习到期 → 低分推进 → 新内容"自动排好）
2. 选第一条开始学习（看书/视频/写代码/做题均可）
3. 学完回到对应任务，点【打分】→ 在【打分弹窗】选档位（0 没碰过 / 30 见过 / 60 能用 / 80 掌握 / 95 精通）
4. 在【证据输入框】写一句"做了什么证明这个分数"（如：独立写了一个计算器）→ 保存
5. 到【日志】页补一条当天学习心得（选填）

**结果说明：** 该知识点掌握度更新、技能进度环变化；打分证据自动进日志；系统按间隔自动安排下次复习日期。

> 注意：分数必须对应真实证据——"看完了视频"最多值 30 分，能独立做出来才值 60+。这是系统的核心规则。

---

### 流程 2：到期复习

解决「学过的东西忘了」——到点自测，会就拉长间隔，不会就重学。

**操作步骤：**

1. 打开看板，右上角【🔥 连续天数】旁的红色徽标数字 = 今天到期复习条数
2. 切到【复习】页 → 列表显示到期节点（含逾期天数、当前掌握度）
3. 对第一个节点**先自己回想**（不看资料），再点【自测复习】
4. 按回想程度选：90 全想起来 / 70 想起大半 / 40 基本忘了
5. 重复直到清空列表

**结果说明：** ≥80 分 → 掌握度 +5、复习间隔拉长一档（1→2→4→7→15→30 天）；60-79 → 维持；<60 → 降档 -15 分、明天重来。结果自动入日志。

> 注意：自测的价值在于"先回想再确认"，直接翻资料再答等于没测。

---

### 流程 3：查看/维护技能树

解决「全局掌握情况如何、技能树不符合实际怎么改」。

**操作步骤：**

1. 看板点击任意【技能卡片】→ 直接进入【技能树】页并切到该技能
2. 按主题分组浏览每个知识点的【状态标签】（未开始/学习中/巩固中/已掌握/已精通）与【📅 下次复习日期】
3. 点主题行可折叠/展开；任意节点右侧点【打分】可直接修正掌握度
4. 点右上【＋ 添加节点】→ 输入标题与验证方式，新增知识点

**结果说明：** 技能进度 = 所有叶子节点掌握度平均值，树顶百分比与看板进度环实时一致。

---

### 流程 4：里程碑与成就记录

解决「阶段目标怎么跟踪」。

**操作步骤：**

1. 看板【🏁 里程碑】区勾选已达成的目标（如"交付一个 Spring Boot Web 服务"）
2. 勾选后自动写入一条项目日志（🏁 前缀），可在【日志】页回看
3. 日志页也可直接手写记录，支持关联技能

**结果说明：** 里程碑打勾即完成，进度可追溯，连续打卡天数从日志日期自动统计。

---

### 流程 5：读课文、做例题

解决「知识点只有标题没有内容」——课文与例题都在技能树里。

**操作步骤：**

1. 【技能树】→ 选技能 → **点击知识点标题**展开课文（有【例题 N】按钮的节点才有正式课文；没有课文时显示卡片摘要）
2. 课文按教材五段式呈现：学习目标 → 课文（含代码示例/表格）→ 易错与陷阱 → 小结与自检
3. 读完点该节点的【例题 N】→ 逐题作答（选项点击即判分），看解析与本知识点正确率统计
4. 全部答完点【用本次结果打分】→ 打分弹窗自动预填证据（如"例题 3/4 正确"）→ 选档位保存

**结果说明：** 掌握度第一次有了客观凭证；作答记录沉淀在 answers 表，正确率随复习持续累积。

> 注意：课文文件是即时生效的——用编辑器改 md 后刷新页面即可看到，无需重启。

---

### 流程 6：内容目录管理与数据备份

解决「课文放哪、数据怎么保险」。

**操作步骤：**

1. 点击 header 的【📁 目录】→ 弹窗显示数据目录与已添加的内容目录（含是否存在、几篇课文）
2. 【添加目录】输入框填路径 → 添加（数据根内的目录会自动存为相对路径，同步/换机器不丢）
3. 【备份快照】按钮 → 生成一致性备份到 `数据根\backup\evo-时间戳.db`（运行中执行也安全）
4. 【移除】可解除目录绑定（不删除文件）

**结果说明：** 课文查找按「目录\技能\主题\知识点.md」规则；远程同步盘同步整个数据根即可带走全部数据。

## 常见问题

**Q：课文怎么加？放在哪？**
A：按 `数据根\技能\主题\知识点名.md` 放 md 文件（如 `D:\CloudDriver\EVO\Java\语言基础\泛型.md`），系统自动识别、即时生效；更多目录用【📁 目录】添加。标题里的 `/` 等非法字符文件名会自动转全角（如 IO／NIO.md）。

**Q：改了 seed.json 的例题为什么没生效？**
A：seed.json 和前端是**编译期嵌入** exe 的——改完必须重新 `go build -o evo.exe .` 并重启；课文 md 则是即时生效。

**Q：data.db 在哪？会进 git 吗？备份怎么办？**
A：在数据根 `D:\CloudDriver\EVO`（不在仓库内，.gitignore 双重排除）。备份：点【📁 目录】→【备份快照】，或直接复制该文件；换机器 = GitHub 拉代码 + 同步盘拉数据根。

**Q：端口 8765 被占用（address already in use）？**
A：服务已在跑或上次没退干净。任务管理器结束 evo.exe 进程再启动。

**Q：为什么我打了 60 分，进度只涨了一点点？**
A：技能进度是**叶子节点**平均值——只给一个点打分，31 个知识点的技能只涨约 2%，这是设计行为。
