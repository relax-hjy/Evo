## 决策日志
- **2026-11-10**：首版后端用 Python FastAPI，原因是单人本地系统、毫秒响应足够、开发最快
- **2026-11-11**：后端改用 Go 重写，原因是性能与单 exe 部署，且 Go 是学习者主攻技能、重写即练手项目
- **2026-11-11**：迁移采用双跑策略（Python 8765 / Go 8766，对拍一致后切换），原因是迁移期系统持续可用
- **2026-11-11**：Go 重写采用教学模式（学习者写、AI review；学习者明确要求时代写），原因为学习目的优先于交付速度
- **2026-11-11**：M6 起 Go 正式接管 8765、Python 下线但代码保留回滚，原因是三轮对拍已证等价且单 exe 部署更简
- **2026-11-12**：全部数据收敛到 `D:\CloudDriver\EVO`（evo.json 配置数据根、content_dirs 存相对路径、VACUUM INTO 快照备份），原因是用户要做远程同步且仓库与数据分离（代码走 GitHub、数据走同步盘）
- **2026-11-12**：教材内容采用「runoob 直接整理入库 + 按技能分批 + 映射表先审 + 批次审校」，课文只存数据根不进 GitHub，原因是版权控制（不公开传播）与学习者把关内容质量
